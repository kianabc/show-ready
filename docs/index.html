What makes it different

Photo enhancement a listing agent can defend.

🏠

The house stays the house

Permanent structure, room size, perspective and the view are locked down. Power lines and the neighbor's house stay where they are.

🛡️

It checks its own work

Every AI edit is compared against the original, edge by edge. A result that redrew the house gets a warning, not a pass.

📋

Disclosure built in

Materially altered photos are flagged in an edit log and can carry a "virtually enhanced" filename, so MLS disclosure is a copy-paste, not a memory test.

💸

It shows what it costs

Bring your own OpenAI key. Estimated cost before each photo, actual cost after, and a running ledger.

🌇

Twilight without a reshoot

Golden hour, sunset and dusk as relight-only edits — the light changes, the architecture doesn't.

🔄

It updates itself

When a new version is out, it asks. One click downloads it, verifies it was signed by the same developer, and restarts.

🔒

Your photos, your key, your Mac

Photos only leave your Mac for the AI edits you choose, sent directly to OpenAI with your own API key. The free local enhance never uploads anything. No accounts, no telemetry, and exports strip location and camera metadata.

Installing

A minute, once. After that it keeps itself up to date.

  1. DownloadThe .dmg from the button above.
  2. DragDouble-click it and drag Rocco Show Ready to Applications.
  3. OpenSigned and notarised, so it opens with one click — no security warnings.
  4. Add a keyOptional: paste an OpenAI API key in Settings to unlock the AI edits.

The free local enhance works with no key at all. Requires macOS 14 or later.
